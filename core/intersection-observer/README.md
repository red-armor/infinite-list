# intersection-observer

A utility package for handling Intersection Observer functionality.

## Overview

This package provides a wrapper around the browser's [Intersection Observer API](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API), making it easier to detect when elements enter or leave the viewport.
